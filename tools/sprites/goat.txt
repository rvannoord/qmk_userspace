// Goat for the right half of the 128x64 panel, beside Bjorn. Faces left (toward Bjorn).
// Frame 30x23. Bottom row is the floor row (panel y=62); the floor rule at y=63 is not in the frame.
// Ink is lit: outline, eye, horn, hooves. The white coat stays dark. No dither.
// The head is carried up on a short neck, chin level with the back, as in the source art; the horn is a short swept-back wedge.
// The standing body spans x5-24, so its centre is the frame centre (x14.5):
// mirror the whole frame in place to face right and the body does not jump.
// Tail region x23-25 y9-11: copy it from stand_tail onto stand, or from graze_tail onto either graze frame.
// Ear region x13-19 y4-9: copy it from stand_ear onto stand. The two regions do not touch.
// Hooves on the floor row, stand / graze / look_up: x5-7, x9-10, x17-18, x20-21.
// hop_air has an empty floor row by design; lift it with the hop offset.
// The back marking is 2x1 dashes, the thinnest ink in the set; nothing else is a lone pixel or a free 1-px line.
//
// Every timing is a multiple of 50 ms (20 Hz).
// Tail: an uneven 3.75 s pattern (single flick, long gap, double flick). Ear: 4.3 s. Breath: 2.8, 3.05, 3.45 s in turn,
// never Bjorn's 3.6 s. The hop borrows walk_b for 50 ms as the push-off and again as the reach before landing.
